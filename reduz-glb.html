Reduzir GLB para o catálogo

Diminui as texturas de um carro em GLB para caber no envio pelo site do GitHub (até 25 MB por arquivo; o ideal é até 15 MB). Tudo roda neste navegador: o arquivo não sai do computador. A malha, os materiais e os nomes das peças (usados para achar as rodas) ficam como estão.

Texturas com transparência continuam em PNG; as outras viram JPEG. Uma textura só é trocada quando a nova fica menor.
